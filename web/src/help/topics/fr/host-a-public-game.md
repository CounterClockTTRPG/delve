---
title: Organiser une partie publique
summary: Laissez les joueurs de ce Delve trouver votre table et demander à la rejoindre.
---
Une table est privée jusqu'à ce que vous en décidiez autrement : seules les personnes ayant son lien d'invitation
peuvent la rejoindre. Pour que d'autres la trouvent, ouvrez la page de la campagne et sa **Présentation de la table**,
dans l'onglet **Aperçu**.

1. Sous **Qui peut trouver la table**, choisissez **Publique**. Les comptes de ce Delve peuvent maintenant la trouver
   dans **Trouver une table** et demander à la rejoindre ; le lien d'invitation fonctionne toujours.
2. Réglez **Places pour les joueurs**, ou laissez vide pour ne pas fixer de limite. Vous et ceux qui regardent
   n'occupez pas de place.
3. Écrivez **À propos de cette table, pour les joueurs** : comment vous jouez ensemble et si les nouveaux venus sont
   les bienvenus. Seuls les joueurs le lisent ; le DM jamais. Dites plutôt au DM comment jouer dans le ton
   personnalisé : sur l'écran de jeu, **Options de table**, **Ton**, **Personnalisé**.
4. Choisissez **Enregistrer la présentation**.

**Trouver une table** montre aussi aux joueurs les règles maison en vigueur, combien de places sont prises et, une
fois que vous avez fixé un horaire, quand la table joue la prochaine fois.

Les demandes pour rejoindre s'affichent sur l'écran de jeu, dans la colonne latérale, où vous admettez qui vous voulez
à votre table : voir [Inviter des joueurs](/help/invite-players).
